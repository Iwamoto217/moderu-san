# 藻出ルさん

KFC（Keio Fashion Creator）ショー当日のモデル管理アプリです。

- 受付：モデルが来たら「到着」、ギャラを渡したら「ギャラを渡した」（事務所モデルは「完了にする」）
- 出口のiPad：モデル本人が、外に出るとき・戻ったときに自分の番号をタッチ
- 運営：誰が未到着か、誰が外出中か、何分出ているかを一覧で確認

## しくみ

- 記録は「何時に・誰が・何をしたか」を1行ずつ足していくだけで、上書きはしません。複数の端末から同時に押しても食い違いません
- 押した記録はまず端末の中に保存され、Googleスプレッドシートへ送られます。電波が切れても端末に残り、つながったら自動で再送します。同じ記録が二重に書かれることはありません
- 一度開いた端末なら、電波がなくても画面を開けます
- 運営ボードの「記録をCSVで保存」で、手元にも控えを残せます

## 準備（最初に1回だけ）

### 1. スプレッドシートとサーバー（GAS）

1. Googleドライブで新しいスプレッドシートを作る（名前は「藻出ルさん_記録」など）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からあるコードを全部消して、`gas/Code.gs` の中身を貼り付けて保存
4. 上の関数の選択で `setup` を選んで「実行」→ 権限の確認が出たら許可する（「名簿」「記録」「設定」の3シートができる）
5. 右上の「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 「デプロイ」を押すと出てくる `https://script.google.com/macros/s/……/exec` のURLを控える

### 2. 画面（GitHub Pages）

1. このフォルダの中身をGitHubのリポジトリに置く
2. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして保存
3. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が開けるようになる

### 3. 配布用リンク

サーバーのURLは、モデルの名前を守るためリポジトリには書きません。代わりに、配るリンクの後ろに付けます。

```
https://<ユーザー名>.github.io/<リポジトリ名>/?api=<手順1-6のURL>
```

このリンクを受付のPC・出口のiPad・スタッフのスマホで一度開けば、その端末はURLを覚えます。

## 当日の使い方

1. 運営ボードの「モデル名簿」に「番号 名前」を1行ずつ貼って保存（事務所モデルは行末に「事務所」）。スプレッドシートの「名簿」シートを直接書き換えてもOK
2. 出口のiPadは、上の「出口タッチ端末」に切り替えて置く
3. 受付のPCは「運営ボード」のまま使う
4. 終わったら「記録をCSVで保存」で控えを残す

右上の表示が「同期済み 時刻」なら、スプレッドシートまで届いています。「未送信 ◯件」と出ている間は、端末の中に保存されていて、つながったら自動で送られます。

## 注意

- 配布リンクを知っている人は、記録を読んだり書いたりできます。リンクは運営メンバーの中だけで共有してください
- サーバーのコードを直したときは、Apps Scriptで「デプロイを管理」→ 編集 →「新しいバージョン」で更新すると、URLが変わりません
